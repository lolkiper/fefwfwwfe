# DramaStill

Программа для Windows, которая собирает длинное драматическое YouTube-видео от идеи до MP4.

На проект приходится **одно** изображение. Оно лежит в кадре от первой до последней секунды: медленный зум, небольшой сдвиг камеры, искры, пыль и полоски визуализатора. Полоски считаются по реальной громкости озвучки, а не по случайной анимации. Второй кадр программа не заказывает.

## Что делает кнопка «Создать новое видео»

1. Языковая модель придумывает оригинальную историю, главы и один драматический момент.
2. Проверяет, что имена, возраст и события не противоречат друг другу.
3. Сервис изображений рисует один кадр 16:9. Внешность персонажей входит в этот запрос.
4. Текст читается выбранным голосом, длинные главы режутся на части и склеиваются.
5. FFmpeg оживляет тот же кадр на всю длину озвучки, добавляет частицы и визуализатор.
6. Рядом с MP4 сохраняются превью, название, описание и теги.

Превью — это тот же кадр с крупной подписью, а не новая генерация.

Ролик на 40–60 минут поддерживается: сценарий пишется по главам, озвучка и видео собираются фрагментами. Уже готовые фрагменты при повторе не создаются заново. После паузы или сбоя проект можно продолжить.

## Установка

Нужны Python 3.11+ и FFmpeg (`ffmpeg` и `ffprobe` в PATH либо путь в разделе «Видео»).

```bat
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
run.bat
```

На Linux и macOS: `python3 -m dramastill`.

Готовая программа для Windows — архив `DramaStill-windows.zip` из сборки GitHub Actions. Снаружи в нём только инструкция и `DramaStill.7z`: браузер блокирует обычный zip, если программа лежит в нём открыто. Пароль `DramaStill.7z` — `dramastill`. Откройте его через 7-Zip и запустите `DramaStill.exe`. Python ставить не нужно.

Собрать тот же архив у себя:

```bat
build_windows.bat
```

Скрипт ставит зависимости, собирает окно через PyInstaller и скачивает FFmpeg в `dist\DramaStill\`. Если видеокарта NVIDIA отвечает, кодирование переключается на NVENC. Иначе используется libx264. Ошибка запуска пишется в `%APPDATA%\DramaStill\startup-error.log`.

## Ключи

Ключи вводятся в разделе «API и ключи». В базу проектов и в журнал они не записываются.

- В Windows файл ключей закрывается DPAPI текущего пользователя.
- На других системах файл шифруется Fernet, ключ шифрования лежит рядом с правами только для владельца.
- Озвучка Microsoft Edge TTS ключа не требует. Для неё нужен интернет.
- История и картинка вызывают тот сервис, который выбран в настройках: OpenAI, Anthropic, OpenRouter, Groq, Ollama, Stability или свой совместимый адрес.

Локальный адрес (`localhost`, Ollama) можно оставить без ключа. Длинный ролик делает много запросов к модели и озвучке. Картинка запрашивается один раз.

## Языки и голоса

Русский, испанский, узбекский, английский или свой язык. Для Edge TTS по умолчанию:

- ru-RU-SvetlanaNeural / ru-RU-DmitryNeural
- es-ES-ElviraNeural / es-ES-AlvaroNeural
- uz-UZ-MadinaNeural / uz-UZ-SardorNeural
- en-US-JennyNeural / en-US-GuyNeural

Список можно обновить кнопкой в разделе «Озвучка». Характер речи передаётся в просодию Edge, в инструкции OpenAI и в настройки голоса ElevenLabs.

## Эффекты

Пресеты: спокойный, кинематографический, драматический, тёплая пыль, минимальный. Зум, сдвиг, покачивание, плотность искр, пыль, свет и полоски настраиваются отдельно. Зум остаётся небольшим, чтобы лица не уезжали из кадра. Частицы слабее в центре, где обычно находятся лица.

Сборка идёт кусками. Готовый MP4, `*.jpg` и `*.youtube.json` копируются в выбранную папку. Временные куски после успеха удаляются, если это включено. История, картинка и полная озвучка остаются в папке проекта.

## Проверка

```bash
python3 -m pytest
```

Кнопка «Проверить видеодвижок» собирает короткий ролик на тестовой карточке, без запроса к ИИ. Это не сюжет и не второй кадр проекта.
